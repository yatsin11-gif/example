## Роли в админке — визуальный TL;DR

Источник: [../requirements/feature-spec.md](../requirements/feature-spec.md). Схема — краткая суть, детали в спеке.

### User flow (что видит пользователь)

```mermaid
flowchart TD
    S1[Супер-админ: создать администратора] --> S2[Выбрать уровень доступа]
    S2 --> V{Уровень выбран?}
    V -->|нет| ERR[Сохранение заблокировано]
    V -->|да| S3[Администратор создан]
    S3 --> L[Администратор логинится]
    L --> N[Навигация показывает<br/>только доступные разделы]
    N --> D{Прямой переход<br/>к недоступному разделу?}
    D -->|да| BLOCK[Доступ отклонён]
```

### Что внутри (pipeline)

```mermaid
flowchart LR
    REQ[Запрос администратора к разделу] --> CHECK[Backend: проверка уровня доступа]
    CHECK -->|супер-админ| ALLOW[Доступ разрешён ко всему]
    CHECK -->|уровень не покрывает| DENY[Отклонено]
    CHECK -->|уровень покрывает| ALLOW
```
