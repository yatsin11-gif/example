- Layer: E2E

- Related criteria: Основной поток: номер и SMS-код; Основной поток: карта и оплата
- Related Jira: `backend-account-creation-and-card-binding.md`, `backend-payment-and-powerbank-dispense.md`, `app-main-rental-flow-ui.md`
- Qase case: Не создано
- Tags: `rental`, `terminal`
- Automation status: candidate

#### Preconditions

- Терминал в рабочем состоянии, powerbank доступен на станции.

#### Test Data

- Новый номер телефона, тестовая карта Stripe.

#### Steps

1. Action: ввести номер телефона на экране ввода номера.
   Expected result: система отправляет SMS-код через Twilio.
2. Action: ввести корректный код из SMS.
   Expected result: создаётся аккаунт по номеру телефона.
3. Action: приложить карту и подтвердить оплату.
   Expected result: оплата проходит через Stripe, карта сохраняется в аккаунте, пользователь получает powerbank и SMS-уведомление.
