## Список задач

### Task 1

- Title: BE. Роли. Модель уровней доступа и проверка доступа к разделам
- Repository: `gozap-backend`
- Owner role: Backend engineer
- Зачем нужна задача: нужна основа для хранения роли админа и проверки доступа к разделам на backend, а не только скрытия в UI.
- Scope:
  - модель роли/уровня доступа для админа (супер-админ, админ)
  - endpoint создания админа с указанием уровня доступа, доступный только супер-админу
  - middleware проверки доступа к разделам по уровню роли запрашивающего админа
- Out of scope: гранулярные права на уровне действий, аудит-лог
- Dependencies: нет
- Risks: точный список разделов и их сопоставление уровням доступа не подтверждён
- Definition of done: только супер-админ может создать админа с уровнем доступа; backend отклоняет запросы к разделам вне уровня доступа

### Task 2

- Title: Admin. Создание админа и навигация по уровню доступа
- Repository: `gozap-admin`
- Owner role: Frontend/Admin engineer
- Зачем нужна задача: супер-админу нужен UI создания админа с выбором уровня доступа, а админу — навигация, ограниченная его уровнем.
- Scope:
  - форма создания админа с выбором уровня доступа (видна только супер-админу)
  - построение навигации/меню по уровню доступа текущего админа
  - сообщение об отсутствии доступа при прямом переходе на запрещённый раздел
- Out of scope: гранулярные права на уровне действий
- Dependencies: Task 1

## Порядок поставки

1. Task 1 — модель ролей и backend-проверка доступа.
2. Task 2 — UI создания админа и навигация по доступу.
