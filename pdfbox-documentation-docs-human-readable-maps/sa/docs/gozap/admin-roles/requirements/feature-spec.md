## Проблема

- Сейчас нет разделения доступа внутри админки: непонятно, кто может создавать других администраторов и какие разделы доступны конкретному админу.
- Супер-админ должен иметь возможность создавать других админов с ограниченным уровнем доступа.

## Цель

- Дать супер-админу возможность создавать админов и назначать им уровень доступа.
- Дать обычному админу возможность входить в систему и видеть только те разделы, которые доступны его уровню.

## Не входит в текущую итерацию

- Гранулярные права на уровне отдельных действий (только на уровне разделов).
- Самостоятельное изменение своего уровня доступа админом.
- Аудит-лог действий админов.

## Триггер и аудитория

- Точка входа / триггер: супер-админ создаёт нового админа в админке и указывает его уровень доступа.
- Основная аудитория: супер-админ платформы Gozap.
- Вторичная аудитория: обычные админы.

## Целевое поведение продукта

### Сценарий

1. Супер-админ создаёт другого админа и выбирает для него уровень доступа.
2. Новый админ логинится в админку.
3. Админ видит только разделы, доступные его уровню доступа.

### Правила результата

- Супер-админ имеет полный доступ ко всем разделам и может создавать других админов.
- Админ видит только разделы, разрешённые его уровнем доступа.
- Разделы, не входящие в уровень доступа админа, не должны быть видимы или доступны.

## Бизнес-правила

- Только супер-админ может создавать новых админов и назначать уровень доступа.
- Уровень доступа определяет видимый набор разделов админки для конкретного админа.
