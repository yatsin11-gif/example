## Проблема

- Пользователь должен вручную вводить код из SMS при подтверждении номера телефона на терминале станции, что замедляет аренду.

## Цель

- Дать пользователю возможность автоматически получить вставленный код из SMS без ручного набора.

## Не входит в текущую итерацию

- Альтернативные способы подтверждения (push, email).
- Изменение провайдера SMS.

## Триггер и аудитория

- Точка входа / триггер: пользователь вводит номер телефона на экране станции и ожидает код из SMS.
- Основная аудитория: пользователи терминального приложения станции (`sa/docs/gozap/terminal-rental-app`).
- Вторичная аудитория: партнёры при сбросе пароля по SMS (`sa/docs/gozap/partners-admin`).

## Целевое поведение продукта

### Сценарий

1. Система отправляет SMS-код через Twilio на введённый номер телефона.
2. Код из SMS автоматически вставляется в поле ввода без действий пользователя.

### Правила результата

- Код должен подставляться автоматически, если технически доступен (платформенный autofill).
- Если автоматическая вставка недоступна, пользователь должен иметь возможность ввести код вручную.

## Бизнес-правила

- SMS-код отправляется через Twilio.
- Автоматическая вставка не должна снижать безопасность подтверждения номера (код одноразовый, с ограниченным сроком жизни).

## Пограничные сценарии

- SMS с кодом задерживается или не приходит.
- Автоматическая вставка не срабатывает на конкретном устройстве/ОС терминала.
- Пользователь получает несколько SMS-кодов подряд (повторный запрос).
