## Автоматическая вставка кода из SMS — визуальный TL;DR

Источник: [../requirements/feature-spec.md](../requirements/feature-spec.md). Схема — краткая суть, детали в спеке.

### User flow (что видит пользователь)

```mermaid
flowchart TD
    A[Ввод номера телефона] --> B[SMS с кодом отправлена]
    B --> C{Устройство поддерживает autofill?}
    C -->|да| D[Код вставляется автоматически]
    C -->|нет| E[Пользователь вводит код вручную]
    D --> F[Верификация кода]
    E --> F
    F --> G{Код верный?}
    G -->|нет, лимит превышен| H[Backend требует новый код]
    G -->|да| I[Верификация успешна]
```

### Что внутри (pipeline)

```mermaid
flowchart LR
    REQ[Запрос кода] --> TWILIO[Twilio: отправка SMS]
    TWILIO --> ST1[(OTP code + TTL + счётчик попыток)]
    IN[Ввод кода<br/>auto или manual] --> VER[Верификация]
    VER --> CHK{Попытки превышены?}
    CHK -->|да| INVAL[Код инвалидируется<br/>нужен новый]
    CHK -->|нет| MATCH{Код совпал?}
    MATCH -->|да| OK[Успех]
    MATCH -->|нет| ST1
```

> Этап в конвейере: **QA test cases готовы**, ожидает ручного QA review и Qase sync. См. [../../../PROGRESS.md](../../../PROGRESS.md).
